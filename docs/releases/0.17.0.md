## Portable verification

Save the patch from this checkout to an absolute path, then use a disposable clone of the
[public repository](https://github.com/ayayaQ/vivi). The following shell commands reconstruct
the original metadata **tree**, without requiring the local-only commit or packet bundle:

```sh
git clone https://github.com/ayayaQ/vivi.git vivi-0.17.0-source
cd vivi-0.17.0-source
git checkout --detach 3c8ab12a1cd52f384f4953eb69f8e80553a49bc2
git apply --index /absolute/path/to/metadata.patch
git write-tree
# Expected: b9f1225fd5210391198d258117d8962893eb3791
git diff --cached --stat
```

The patch is an email-format patch, but `git apply --index` deliberately reconstructs a
tree rather than promising to reproduce the original commit's identity. Preserve Git's
index representation when comparing source bytes; Windows checkout line endings can differ.

Download the archive from the public link above. This Python 3 verification, run inside
the reconstructed clone with the archive path as its argument, checks hashes, all 93
source/documentation files and all export targets without installing or executing a package:

```python
import base64, hashlib, json, subprocess, sys, tarfile
from pathlib import Path, PurePosixPath

raw = Path(sys.argv[1]).read_bytes()
assert len(raw) == 452430
assert hashlib.sha256(raw).hexdigest() == "f709f18cc262f0b6c56170cb4d5fa47ab196b1039833aa0795e61598b55b49a0"
assert hashlib.sha1(raw).hexdigest() == "17212d3a1fb80e4a569dc85025f032f80ddfae6c"
assert "sha512-" + base64.b64encode(hashlib.sha512(raw).digest()).decode() == "sha512-inMbmRN+0RGtZZKtjhq9TsmwNJHVlqo4TyKsKSGD6wtPGQUBXI18U4kTk5AV6V4ehKoWx9RD5WrBpZv8M/i/Jw=="
files = {}
with tarfile.open(sys.argv[1]) as archive:
    for member in archive:
        path = PurePosixPath(member.name)
        assert member.isfile() and path.parts[0] == "package"
        assert not path.is_absolute() and ".." not in path.parts
        name = path.relative_to("package").as_posix()
        assert name not in files
        files[name] = archive.extractfile(member).read()
assert len(files) == 430
source_count = 0
for name, contents in files.items():
    if not name.startswith("dist/"):
        expected = subprocess.check_output(["git", "show", "b9f1225fd5210391198d258117d8962893eb3791:" + name])
        assert contents == expected, name
        source_count += 1
assert source_count == 93
manifest = json.loads(files["package.json"])
assert manifest["name"] == "@ayayaq/vivi" and manifest["version"] == "0.17.0"
assert len(manifest["exports"]) == 17
def check_targets(value):
    if isinstance(value, str):
        assert value.removeprefix("./") in files, value
        return 1
    return sum(check_targets(child) for child in value.values())
assert check_targets(manifest["exports"]) == 68
print("Verified archive identity, 93 source files and 68 export targets")
```

## Reproducibility limits

The published archive includes preparation-era prose saying that 0.17.0 was unpublished.
Those bytes are immutable. The current README, changelog, release guide and API guide
describe the verified published state, and this provenance directory is new. Consequently
a pack from the reconciled checkout has different documentation, contents and archive
hash even with an identical build. It must never substitute for the published archive.

Source-tree equality, compiled-byte equality, tarball-byte equality, installed-consumer
behavior and host readiness are distinct claims. This record establishes the original
metadata reconstruction and registry/archive identity. It does not establish new remote
CI, manual/native UI behavior, live provider/OAuth behavior, registry signature validation,
or the availability of the local-only metadata commit on a remote.
